## Edge Case Analysis

### 1. Null Semantics

**Case 1: Field is null**
- Meaning: No disk encryption set specified, use platform-managed keys
- Handling: The `diskEncryptionSet` object is omitted from the `managedDisk` structure
- Azure Behavior: Platform-managed encryption is used

**Case 2: Field transitions null → value**
- Meaning: Enable customer-managed key encryption
- Handling: Standard update via AzAPI
- Azure Behavior: Disk is encrypted with the specified disk encryption set

**Case 3: Field transitions value → null**
- Meaning: User wants to remove customer-managed encryption
- Handling: AzAPI will send null value
- Azure Behavior: **This is blocked by Azure API** - "once a customer-managed key is used, you can't change the selection back to a platform-managed key"
- **Note:** The provider has explicit error handling for this case. We cannot replicate this check without complex state comparison logic. Azure API will reject this operation with an appropriate error.

**Case 4: Field transitions value1 → value2**
- Meaning: Change to a different disk encryption set
- Handling: Standard update via AzAPI
- Azure Behavior: Disk encryption is updated to use the new encryption set
