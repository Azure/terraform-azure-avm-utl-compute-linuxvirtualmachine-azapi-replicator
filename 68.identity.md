**Azure API Documentation:**

- `userAssignedIdentities`: A list of User Managed Identity ID's which should be assigned to the azure resource
- `principal_id`: (Computed) The Principal ID for the Service Principal associated with the Managed Service Identity
- `tenant_id`: (Computed) The Tenant ID for the Service Principal associated with the Managed Service Identity
