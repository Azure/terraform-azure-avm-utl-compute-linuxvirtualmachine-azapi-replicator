### Validation

The provider uses `computeValidate.VirtualMachineName` which implements comprehensive validation:

```go
func VirtualMachineName(i interface{}, k string) (warnings []string, errors []error) {
	v, ok := i.(string)
	if !ok {
		errors = append(errors, fmt.Errorf("expected %q to be a string but it wasn't", k))
		return
	}

	// The value must not be empty.
	if strings.TrimSpace(v) == "" {
		errors = append(errors, fmt.Errorf("%q must not be empty", k))
		return
	}

	const maxLength = 80
	// VM name can be 1-80 characters in length
	if len(v) > maxLength {
		errors = append(errors, fmt.Errorf("%q can be at most %d characters, got %d", k, maxLength, len(v)))
	}

	if matched := regexp.MustCompile(`^[a-zA-Z0-9._-]+$`).Match([]byte(v)); !matched {
		errors = append(errors, fmt.Errorf("%q may only contain alphanumeric characters, dots, dashes and underscores", k))
	}

	if matched := regexp.MustCompile(`^[a-zA-Z0-9]`).Match([]byte(v)); !matched {
		errors = append(errors, fmt.Errorf("%q must begin with an alphanumeric character", k))
	}

	if matched := regexp.MustCompile(`\w$`).Match([]byte(v)); !matched {
		errors = append(errors, fmt.Errorf("%q must end with an alphanumeric character or underscore", k))
	}

	// Portal: Virtual machine name cannot contain only numbers.
	if matched := regexp.MustCompile(`^\d+$`).Match([]byte(v)); matched {
		errors = append(errors, fmt.Errorf("%q cannot contain only numbers", k))
	}

	return warnings, errors
}
```

**Replicated in variables.tf:**
All validation rules from the provider are implemented as separate validation blocks:
1. Must contain only alphanumeric characters, dots, dashes, and underscores
2. Must begin with an alphanumeric character
3. Must end with an alphanumeric character or underscore
4. Cannot contain only numbers
5. Must be between 1 and 80 characters in length

## Critical Review & Edge Case Analysis

### Null Semantics
- **Variable:** `nullable = false` - the name must always be provided
- **Required:** Yes, this is a required argument
- **Meaning:** Name cannot be null; it must be a valid string

### Boundary Conditions
- **Empty string:** Rejected by validation (length must be >= 1)
- **Only whitespace:** Would fail the regex pattern validation (no spaces allowed)
- **Maximum length:** 80 characters (validated explicitly)
- **Special characters:** Only alphanumeric, dots, dashes, and underscores allowed

### Idempotency
- The name is a simple string value with no order-dependent behavior
- ForceNew ensures that any change to the name creates a new resource (idempotent)
- No array operations or merge logic involved

### Safe References
- Direct reference to `var.name` is safe as it's a required, non-nullable field
- No nested property access required
- No risk of null pointer exceptions

### Edge Cases
1. **Name starting with number:** Rejected by validation (must start with alphanumeric, and cannot be only numbers)
2. **Name ending with dash or dot:** Rejected by validation (must end with alphanumeric or underscore)
3. **Unicode characters:** Rejected by validation (only ASCII alphanumeric, dots, dashes, underscores allowed)
4. **Case sensitivity:** Azure resource names are case-insensitive, but the validation preserves the case provided by the user
