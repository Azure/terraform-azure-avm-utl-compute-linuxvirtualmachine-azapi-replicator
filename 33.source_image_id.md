### Expand Function Logic

The `expandSourceImageReference` function determines which field to populate based on the image ID format:

```go
func expandSourceImageReference(referenceInput []interface{}, imageId string) *virtualmachines.ImageReference {
    if imageId != "" {
        // Community Gallery: "/communityGalleries/.../images/.../versions/..."
        if _, errors := validation.Any(validate.CommunityGalleryImageID, validate.CommunityGalleryImageVersionID)(imageId, "source_image_id"); len(errors) == 0 {
            return &virtualmachines.ImageReference{
                CommunityGalleryImageId: pointer.To(imageId),
            }
        }

        // Shared Gallery: "/sharedGalleries/.../images/.../versions/..."
        if _, errors := validation.Any(validate.SharedGalleryImageID, validate.SharedGalleryImageVersionID)(imageId, "source_image_id"); len(errors) == 0 {
            return &virtualmachines.ImageReference{
                SharedGalleryImageId: pointer.To(imageId),
            }
        }

        // Regular image ID (default)
        return &virtualmachines.ImageReference{
            Id: pointer.To(imageId),
        }
    }

    // Handle source_image_reference (not applicable for this task)
    raw := referenceInput[0].(map[string]interface{})
    return &virtualmachines.ImageReference{
        Publisher: pointer.To(raw["publisher"].(string)),
        Offer:     pointer.To(raw["offer"].(string)),
        Sku:       pointer.To(raw["sku"].(string)),
        Version:   pointer.To(raw["version"].(string)),
    }
}
```

### Implementation Strategy

Since the provider uses conditional logic to populate different fields based on the image ID format, we must replicate this logic in Terraform:

1. Check if the ID matches Community Gallery format → populate `communityGalleryImageId`
2. Check if the ID matches Shared Gallery format → populate `sharedGalleryImageId`
3. Otherwise → populate `id` (regular image ID)
