- **Result:** ✅ Null means "do not send to API"

- **Terraform Input:** Empty string `""`
- **Provider Behavior:** Read method returns empty string as default when not set
- **API Behavior:** According to Azure API docs, valid values are "Unknown", "IfRequired", "Never", "Always"
- **Validation:** Our validation requires one of three specific values, empty string would fail validation
- **Result:** ✅ Empty string rejected by validation (correct behavior)

- **Provider Values:** "Always", "IfRequired", "Never"
- **API Values:** "Unknown", "IfRequired", "Never", "Always"

- **Result:** ✅ Idempotent behavior maintained
