## DiffSuppressFunc Implementation

**Provider DiffSuppressFunc Source:**
```go
func adminPasswordDiffSuppressFunc(_, old, new string, _ *pluginsdk.ResourceData) bool {
    // this is not the greatest hack in the world, this is just a tribute.
    if old == "ignored-as-imported" || new == "ignored-as-imported" {
        return true
    }

    return false
}
```

**Behavior:**
The function suppresses the diff when either the old or new value equals the special string `"ignored-as-imported"`. This is used during import operations where the actual password cannot be retrieved from Azure API (passwords are write-only), so the provider uses this sentinel value.

**Terraform Translation:**
```hcl
locals {
  should_read_existing_admin_password = var.admin_password != null
  
  existing_admin_password = local.should_read_existing_admin_password && data.azapi_resource.existing.exists
    ? try(data.azapi_resource.existing.output.properties.osProfile.adminPassword, null)
    : null
  
  desired_admin_password = var.admin_password
  
  admin_password_should_suppress = (
    local.existing_admin_password == "ignored-as-imported" || 
    local.desired_admin_password == "ignored-as-imported"
  )
  
  effective_admin_password = local.admin_password_should_suppress
    ? coalesce(local.existing_admin_password, local.desired_admin_password)
    : local.desired_admin_password

```

**State Handling:**
- Reads existing state via `data.azapi_resource.existing` when `admin_password` is provided
- Safely handles cases where resource doesn't exist yet (returns null)
- Uses `try()` to handle missing osProfile or adminPassword fields

**Effective Value Selection:**
- When suppression applies: reuses existing value, falls back to desired value if existing is null
- When suppression doesn't apply: uses desired value
- This ensures idempotent behavior while respecting the import sentinel value

## Validation Implementation

**Provider Validation Function (LinuxAdminPassword):**
```go
func LinuxAdminPassword(i interface{}, k string) (warnings []string, errors []error) {
    v, ok := i.(string)
    if !ok {
        errors = append(errors, fmt.Errorf("expected %q to be a string but it wasn't", k))
        return warnings, errors
    }

    if strings.TrimSpace(v) == "" {
        errors = append(errors, fmt.Errorf("%q must not be empty", k))
        return warnings, errors
    }

    // Length validation: 6-72 characters
    if len(v) < 6 || len(v) > 72 {
        errors = append(errors, fmt.Errorf("%q most be between %d and %d characters, got %d", k, 6, 72, len(v)))
    }

    // Disallowed values
    disallowedNames := []string{"abc@123", "P@$$w0rd", "P@ssw0rd", "P@ssword123", "Pa$$word", "pass@word1", "Password!", "Password1", "Password22", "iloveyou!"}
    for _, value := range disallowedNames {
        if value == v {
            errors = append(errors, fmt.Errorf("%q specified is not allowed, got %q, cannot match: %q", k, v, strings.Join(disallowedNames, ", ")))
        }
    }

    // Complexity requirements: 3 out of 4 conditions
    conditions := 0
    tests := []string{"[a-z]", "[A-Z]", "[0-9]", "[^\\d\\w]"}
    for _, test := range tests {
        t, _ := regexp.MatchString(test, v)
        if t {
            conditions++
        }
    }
    if conditions < 3 {
        errors = append(errors, fmt.Errorf("%q has to fulfill 3 out of these 4 conditions: Has lower characters, Has upper characters, Has a digit, Has a special character other than \"_\", fullfiled only %d conditions", k, conditions))
    }

    return warnings, errors
}
```

## Edge Case Analysis

### 1. Null Semantics
- **`null` meaning:** Field not provided - omitted from API request
- **Behavior:** When `null`, osProfile.adminPassword is not sent to API
- **Safe:** Conditional inclusion prevents sending null value

### 2. Empty String
- **Validation:** Catches empty strings via length validation (minimum 6 characters)
- **Provider check:** Also validates non-empty in Create method
- **Safe:** Double protection against empty passwords

### 3. Import Sentinel Value
- **Special value:** `"ignored-as-imported"`
- **Purpose:** Used during import when password can't be read from API
- **Handling:** DiffSuppressFunc prevents false diffs when this value is present
- **Safe:** Proper suppression logic implemented

### 4. Conditional Requirement
- **Scenario:** Required when `disable_password_authentication` is `false`
- **Implementation:** Cross-variable validation checks this condition
- **Safe:** Validation fails at plan time if requirement not met

### 5. Write-Only Field
- **Behavior:** Azure API never returns the password value
- **Impact:** Reading existing state will return null (or sentinel value after import)
- **Handling:** 
  - `try()` safely handles missing field
  - DiffSuppressFunc handles sentinel value
  - Falls back to desired value when existing is null
- **Safe:** Robust handling of all cases

### 6. ForceNew with Sensitive
- **Challenge:** Can't expose sensitive value in replace triggers
- **Solution:** Use `admin_password_version` (non-sensitive) to track changes
- **Safe:** Version variable acts as change indicator without exposing password

### 7. Idempotency
- **DiffSuppressFunc:** Ensures repeated applies don't trigger changes when sentinel value is present
- **Conditional inclusion:** Consistent behavior - field only sent when provided
- **Safe:** Implementation is idempotent

### 8. Safe References
- **All nested accesses use `try()`:** Prevents errors if path doesn't exist
- **Existence checks:** `data.azapi_resource.existing.exists` before accessing output
- **Safe:** No risk of errors from missing fields
