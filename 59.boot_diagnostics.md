## Hidden Fields Check

**Expand Function Analysis:**

```go
func expandBootDiagnostics(input []interface{}) *virtualmachines.DiagnosticsProfile {
    if len(input) == 0 {
        return &virtualmachines.DiagnosticsProfile{
            BootDiagnostics: &virtualmachines.BootDiagnostics{
                Enabled:    pointer.To(false),
                StorageUri: pointer.To(""),
            },
        }
    }

    if input[0] == nil {
        return &virtualmachines.DiagnosticsProfile{
            BootDiagnostics: &virtualmachines.BootDiagnostics{
                Enabled:    pointer.To(true),
                StorageUri: pointer.To(""),
            },
        }
    }

    raw := input[0].(map[string]interface{})
    storageAccountUri := raw["storage_account_uri"].(string)

    return &virtualmachines.DiagnosticsProfile{
        BootDiagnostics: &virtualmachines.BootDiagnostics{
            Enabled:    pointer.To(true),
            StorageUri: pointer.To(storageAccountUri),
        },
    }
}
```

**Hidden Fields Found:**

1. **`enabled`** - Not exposed in Terraform schema but set by provider:
   - When `boot_diagnostics` block is **not set** (null): `enabled = false`, `storageUri = ""`
   - When `boot_diagnostics` block is **set but empty**: `enabled = true`, `storageUri = ""`
   - When `boot_diagnostics.storage_account_uri` is set: `enabled = true`, `storageUri = <value>`

2. **Empty string for `storageUri`** - Provider always sets `storageUri`, even when not specified by user:
   - When not using custom storage account: `storageUri = ""` (enables managed boot diagnostics)

**Implementation Decision:** The skeleton includes the logic for when `boot_diagnostics` is null (disabled state). The enabled state with field values will be implemented by Task #60.

## Edge Case Analysis

1. **Null vs Empty Block:**
   - `boot_diagnostics = null` → Disabled boot diagnostics (`enabled = false`)
   - `boot_diagnostics = {}` → Managed boot diagnostics (`enabled = true`, empty `storageUri`)
   - The skeleton correctly handles the null case; Task #60 will handle the enabled cases

2. **Empty String Semantics:**
   - Provider always sets `storageUri` to empty string when not using custom storage
   - This is intentional for managed boot diagnostics feature

3. **State Transitions:**
   - Null → Set: Enable boot diagnostics (updateable)
   - Set → Null: Disable boot diagnostics (updateable)
   - No ForceNew, all transitions are updates

4. **Idempotency:**
   - When null, always outputs same disabled state
   - When set, child task will ensure idempotency for field values
