## Expand Function Analysis

**Function:** `expandVirtualMachineNetworkInterfaceIDs`

**Source Code:**
```go
func expandVirtualMachineNetworkInterfaceIDs(input []interface{}) []virtualmachines.NetworkInterfaceReference {
	output := make([]virtualmachines.NetworkInterfaceReference, 0)

	for i, v := range input {
		output = append(output, virtualmachines.NetworkInterfaceReference{
			Id: pointer.To(v.(string)),
			Properties: &virtualmachines.NetworkInterfaceReferenceProperties{
				Primary: pointer.To(i == 0),  // <- First element is primary
			},
		})
	}

	return output
}
```

**Key Behavior:**
- Iterates through the input list
- For each network interface ID, creates a `NetworkInterfaceReference` object
- **CRITICAL:** Sets `Primary: true` for the **first** element (i == 0), false for all others
- All elements get a `properties` object with the `primary` field

## Special Handling

### 1. Validation

**MinItems Validation:**
The provider schema specifies `MinItems: 1`, ensuring at least one network interface is provided. This is replicated in `variables.tf`:

```hcl
variable "network_interface_ids" {
  type        = list(string)
  description = "(Required). A list of Network Interface IDs which should be attached to this Virtual Machine. The first Network Interface ID in this list will be the Primary Network Interface on the Virtual Machine."
  nullable    = false

  validation {
    condition     = length(var.network_interface_ids) >= 1
    error_message = "At least one Network Interface ID must be provided."
  }

  validation {
    condition = alltrue([
      for id in var.network_interface_ids : 
      can(regex("^/subscriptions/[a-fA-F0-9-]+/resourceGroups/[^/]+/providers/Microsoft.Network/networkInterfaces/[^/]+$", id))
    ])
    error_message = "Each network_interface_ids element must be a valid Azure Network Interface ID."
  }
}
```

### 2. Primary Network Interface Logic

The expand function automatically marks the **first** element in the list as `primary: true`. This behavior must be replicated in the locals:

```hcl
locals {
  body = {
    properties = merge(
      {

              }

        }
      }

  }

```

### 3. Not ForceNew

The field does **not** have `ForceNew: true` in the schema, meaning network interfaces can be updated without recreating the VM. Therefore, this field is **not** added to `replace_triggers_external_values`.

## Critical Review & Edge Cases

### Null Semantics
- The field is **Required** and **nullable: false**
- An empty list is prevented by the `MinItems: 1` validation
- Null values are not permitted

### Boundary Conditions
- **Minimum:** 1 network interface (enforced by validation)
- **Maximum:** No explicit maximum in provider schema, Azure API limits apply
- **Empty list:** Rejected by validation

### Idempotency
- List order matters: the first element determines the primary network interface
- Reordering the list will cause an update (first element changes `primary` status)
- List is processed in order, maintaining stable primary assignment

### Safe References
- No nested null checks needed - field is Required and list elements are strings
- Each element validated as a proper Network Interface ID format

### Primary Network Interface Behavior
- **First apply:** Element at index 0 becomes primary
- **Update with reorder:** If list order changes, primary may change
- **Update with same order:** Primary remains stable
- **Single element:** That element is always primary
