# Task #25: patch_assessment_mode - Root-Level Argument

## Summary

Implemented `patch_assessment_mode` field conversion from azurerm_linux_virtual_machine to azapi_resource. This field specifies the mode of VM Guest Patching for the Virtual Machine, with possible values "AutomaticByPlatform" or "ImageDefault", defaulting to "ImageDefault". The field is Optional + Computed, can be updated, requires `provision_vm_agent = true` when set to "AutomaticByPlatform", and conflicts with `os_managed_disk_id`.
