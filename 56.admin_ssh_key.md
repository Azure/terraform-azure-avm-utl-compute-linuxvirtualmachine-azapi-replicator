## Hidden Fields

### Expand Function Analysis

The `expandSSHKeys` function reveals a hidden field:

```go
func expandSSHKeys(input []interface{}) []virtualmachines.SshPublicKey {
    output := make([]virtualmachines.SshPublicKey, 0)

    for _, v := range input {
        raw := v.(map[string]interface{})

        username := raw["username"].(string)
        output = append(output, virtualmachines.SshPublicKey{
            KeyData: pointer.To(raw["public_key"].(string)),
            Path:    pointer.To(formatUsernameForAuthorizedKeysPath(username)),
        })
    }

    return output
}

func formatUsernameForAuthorizedKeysPath(username string) string {
    return fmt.Sprintf("/home/%s/.ssh/authorized_keys", username)
}
```

**Hidden Field: `path`**
- Not exposed in Terraform schema
- Computed from `username` field using the format: `/home/{username}/.ssh/authorized_keys`
- This is a standard Linux SSH path convention

**Implementation Note:** Task #58 will implement both the `username` field mapping AND the hidden `path` field computation.

## Edge Case Analysis

### Null Semantics
- `var.admin_ssh_key == null`: SSH configuration not included in linuxConfiguration
- `var.admin_ssh_key == []`: Empty set - SSH configuration not included (handled by conditional)

### Empty Collection
If the set is empty, the conditional `var.admin_ssh_key != null` will still evaluate to true for an empty set. However, the `for` expression will produce an empty array `[]`, which is the correct API representation.

### Set Ordering
Since this is a TypeSet, order is not guaranteed. However, the API accepts an array where order doesn't matter for SSH keys, so this is safe.

### Safe References
All nested access uses conditional checks (`var.admin_ssh_key != null ? {...} : {}`), ensuring no null reference errors.

### Idempotency
The `for` expression iterates over a set, and the output is deterministic for a given set of keys. The SSH key hash function ensures duplicate detection at the Terraform level.
