- **null:** Field not set → No secure boot configuration in API request
- **false:** Explicitly disable secure boot → `secureBootEnabled: false` sent to API
- **true:** Enable secure boot → `secureBootEnabled: true` sent to API

### Boundary Conditions
- **Bool type:** Only three possible values: null, false, true
- **API behavior:** API accepts bool, defaults to false when not specified
- **TrustedLaunch requirement:** Setting secure_boot_enabled=true triggers securityType="TrustedLaunch"
- **ConfidentialVM requirement:** When security_encryption_type="DiskWithVMGuestState", secure_boot_enabled MUST be true

- **Change true → false:** Triggers replacement (ForceNew)
- **Change null → true:** Triggers replacement (ForceNew)
