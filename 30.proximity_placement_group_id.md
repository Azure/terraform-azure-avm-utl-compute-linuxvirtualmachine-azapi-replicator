## Special Handling

### 1. DiffSuppressFunc: suppress.CaseDifference

**Provider Logic:**
The provider uses `suppress.CaseDifference` which suppresses diffs when only case differs between old and new values. This is needed because the Azure API returns the Resource Group name in uppercase (known API bug tracked in Azure/azure-rest-api-specs/issues/19424).

**Implementation Strategy (per diffsuppressfunc.md):**

1. **Read existing state**: When `proximity_placement_group_id` is set, read the current value from `data.azapi_resource.existing.output.properties.proximityPlacementGroup.id`

2. **Compute suppression condition**: Suppress when both values exist and are equal when lowercased:
   ```hcl
   proximity_placement_group_id_should_suppress = (
     local.existing_proximity_placement_group_id != null &&
     local.desired_proximity_placement_group_id != null &&
     lower(local.existing_proximity_placement_group_id) == lower(local.desired_proximity_placement_group_id)
   )
   ```

3. **Select effective value**: When suppression is active, use the existing value (preserves casing from API); otherwise use the desired value:
   ```hcl
   effective_proximity_placement_group_id = local.proximity_placement_group_id_should_suppress 
     ? coalesce(local.existing_proximity_placement_group_id, local.desired_proximity_placement_group_id) 
     : local.desired_proximity_placement_group_id
   ```

4. **Use in body**: The effective value goes into the body
   ```hcl
   proximityPlacementGroup = local.effective_proximity_placement_group_id != null ? {
     id = local.effective_proximity_placement_group_id
   } : null
   ```

**Scenarios:**

| Scenario | Existing Value | Desired Value | Should Suppress? | Effective Value | Explanation |
|----------|---------------|---------------|------------------|-----------------|-------------|
| Initial create | `null` | `/subscriptions/.../ProximityPlacementGroups/ppg1` | No | Desired value | No existing state, use desired |
| Case-only change | `/subscriptions/.../RESOURCEGROUPS/rg/...` | `/subscriptions/.../resourceGroups/rg/...` | Yes | Existing value | Case differs only, suppress diff |
| Real change | `/subscriptions/.../ppg1` | `/subscriptions/.../ppg2` | No | Desired value | Different IDs, allow update |
| Null to value | `null` | `/subscriptions/.../ppg1` | No | Desired value | Adding new value |
| Value to null | `/subscriptions/.../ppg1` | `null` | No | `null` | Removing value |

- **Safe access**: Uses `try()` to handle missing property path
