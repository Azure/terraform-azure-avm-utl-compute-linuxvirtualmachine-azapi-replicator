### 2. Cross-Field Validation

**Provider Validation:**
```go

	return fmt.Errorf("`allow_extension_operations` cannot be set to `true` when `provision_vm_agent` is set to `false`")
```

**Implementation:** Added validation block in `variables.tf`:
```hcl
validation {

  error_message = "allow_extension_operations cannot be set to true when provision_vm_agent is set to false."
```

**Logic Explanation:**
- `!var.allow_extension_operations`: If allow_extension_operations is false, validation passes (any provision_vm_agent value is OK)
- `var.provision_vm_agent != false`: If allow_extension_operations is true, provision_vm_agent must not be explicitly false (null or true are OK)
