## Hidden Fields

**Discovered Hidden Field:** `enable`

The `expandOsImageNotificationProfile` function contains critical hidden logic:

```go
func expandOsImageNotificationProfile(input []interface{}) *virtualmachines.OSImageNotificationProfile {
	if len(input) == 0 {
		return &virtualmachines.OSImageNotificationProfile{
			Enable: pointer.To(false),
		}
	}

	raw := input[0].(map[string]interface{})
	timeout := raw["timeout"].(string)

	return &virtualmachines.OSImageNotificationProfile{
		Enable:           pointer.To(true),
		NotBeforeTimeout: &timeout,
	}
}
```

**Hidden Field Logic:**
1. When `os_image_notification` block is **absent** (len(input) == 0): Sets `Enable` to `false`
2. When `os_image_notification` block is **present**: Sets `Enable` to `true` and includes `NotBeforeTimeout`

**CRITICAL:** The provider ALWAYS returns an `OSImageNotificationProfile` object, even when the block is absent. This hidden `enable` field controls whether the feature is enabled.

**Implementation Decision:** The skeleton handles both states:
- When `var.os_image_notification != null`: Set `enable = true` and include placeholder for `notBeforeTimeout`
- When `var.os_image_notification == null`: Set `enable = false` (no `notBeforeTimeout`)

This hidden field has been implemented directly in this task (Task #71) since it's part of the block structure itself and fundamental to the block's behavior.
