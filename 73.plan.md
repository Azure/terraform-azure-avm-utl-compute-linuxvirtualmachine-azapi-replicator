- `var.plan != null`: Plan block with three required fields (name, product, publisher)

**Validation:**

- All three child fields (name, product, publisher) are Required when the block is present

Since the entire block has ForceNew: true, any change to the plan block (including null ↔ non-null transitions or any field value change) will trigger resource replacement. This is idempotent because:
- Same plan values → no change detected
- Different plan values → replacement triggered

**Safe References:**
The conditional `var.plan != null ? {...} : null` ensures the plan block is only created when the variable is provided, preventing null pointer issues.
